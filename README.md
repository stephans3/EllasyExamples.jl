# EllasyExamples

This repo contains a collection of ladder circuit simulation examples made with [Ellasy.jl](https://github.com/stephans3/Ellasy.jl)


## Article

The source code is used to generate figures for this article:

- S. Scholz, "State space modeling of RLC ladder circuits", [arxiv:2608.01051](https://arxiv.org/abs/2608.01051), 2026
